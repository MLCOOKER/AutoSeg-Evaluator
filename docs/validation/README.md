# Validation

The supplementary validation reports of AutoSeg Evaluator. Each is a short report
(aim, method, results, findings) with a full-results file holding every table
behind it. Both are generated by the scripts named, from data described in each
report; regenerate them rather than editing them.

| | Report | Full results | Generated by |
| --- | --- | --- | --- |
| Supplementary 1 | [DVH Validation Report](Supplementary_1_DVH_Validation_Report.md) | [Full results](Supplementary_1_DVH_Validation_Report_Full_Results.md) | `scripts/validate_dvh_methods.py`, `scripts/validate_dvh_mask_vs_polygon.py` |
| Supplementary 2 | [Binary Mask Rasteriser Validation Report](Supplementary_2_Binary_Mask_Rasteriser_Validation_Report.md) | [Full results](Supplementary_2_Binary_Mask_Rasteriser_Validation_Report_Full_Results.md) | `scripts/validate_rasterisation_fidelity.py` |
| Supplementary 3 | [2D Polygon Metric Validation Report](Supplementary_3_2D_Polygon_Metric_Validation_Report.md) | [Full results](Supplementary_3_2D_Polygon_Metric_Validation_Report_Full_Results.md) | `scripts/validate_polygon_analytic.py` |
| Supplementary 4 | [Google-deepmind/surface-distance Implementation](Supplementary_4_Google-deepmind_surface-distance_Implementation.md) | [Full results](Supplementary_4_Google-deepmind_surface-distance_Implementation_Full_Results.md) | `scripts/validate_surface_distance_equivalence.py` |
| Supplementary 5 | [STAPLE Implementation](Supplementary_5_STAPLE_Implementation.md) | [Full results](Supplementary_5_STAPLE_Implementation_Full_Results.md) | `scripts/validate_staple_against_upstream.py` |

Runs that take more than a minute keep their results in `.validation_cache/` (not
committed), so a report can be rewritten without computing it again: `--render-only`
for Supplementary 2, 3 and 5, and `python scripts/supplementary_1_dvh.py` for
Supplementary 1. Reports from earlier versions are in [`docs/archive`](../archive/README.md).
